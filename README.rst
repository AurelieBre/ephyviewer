Forked from https://github.com/NeuralEnsemble/ephyviewer (for additional information https://ephyviewer.readthedocs.io/en/latest/#).

Modified to support the following features:
-> adding markers on TraceViewer with left clicks on specific channel (TraceViewer_Annotate).
-> encode simultaneously two types of epoch, one with 0-9 keys and one with A-Z keys (EpochEncoder_ABC).
